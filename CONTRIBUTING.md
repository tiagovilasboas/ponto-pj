# Contributing

Issues and PRs are welcome. Keep changes small and scoped.

## Setup

Follow **Start** in the [README](README.md). You need a Supabase project for auth and data.

## Checks

Run before opening a PR:

```bash
npm run lint
npm run type-check
npm run test:run
```

## Commits

Prefer conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.

## Pull requests

- Describe what changed and why
- Do not invent features or expand scope without discussion
- Update docs when setup or behavior changes
